Translated Audiobooks

Books with an audiobook, an English edition, and translations into at least 3 languages — grouped by genre, ranked by the Translation Popularity Index.

How the score (TPI) works

TPI = L + W × Σ log2(k)

  • L — number of languages the book is translated into.
  • k — number of distinct translations into one language (each language with k ≥ 2 contributes).
  • W — retranslation weight (default 25, adjustable below).

Multiple translations into the same language count very high: every doubling of translations in one language is worth W extra languages. Counts are curated, rounded estimates intended for ranking. Source data: data/books.json.
