Translated Audiobooks

Books with an audiobook, an English edition, and translations into at least 3 languages — grouped by genre, ranked by the Translation Popularity Index, with free public-domain EPUB/PDF links (English & Russian).

How the score (TPI) works

TPI = (L + W × Σ log2(k)) × R

  • L — number of languages the book is translated into.
  • k — number of distinct translations into one language (each language with k ≥ 2 contributes).
  • W — retranslation weight (default 25, adjustable below).
  • R — recency boost: books first published in 1950 or later get × (1 + B), default B = 100%, i.e. ×2 (adjustable below). Newer books have had less time to collect retranslations.

Multiple translations into the same language count very high: every doubling of translations in one language is worth W extra languages. Counts are curated, rounded estimates intended for ranking.

Free e-books: links go only to legal public-domain copies — Project Gutenberg (EPUB) and Wikisource (EPUB/PDF via WS Export), in English (EN) and Russian (RU, highlighted). Books under copyright have none. Source data: data/books.json.
